# Installing this version of Cold War: Iron Curtain

This fork adds, on the `iron-curtain-expanded` branch:

- A full Burma focus tree (661 focuses, mostly economy), 44 historical events,
  20 economy decisions, loans and foreign relations
- An economy branch for each era (1950s to 2010s) in every country's focus tree
- 103 historical events with choices for Thailand, Laos, Sri Lanka, Mexico,
  Brazil, Argentina and Japan
- Cabinet ministers and military staff for every country
- Realistic weapon purchase prices (20 jets = $0.4B instead of $80B)
- A picture for every national focus (about 6,000 placeholders replaced)
- The classic HOI4 interface colours
- A background for the Military Industry trait tree (it was black)

## Install with GitHub Desktop

1. Install GitHub Desktop and sign in.
2. File > Clone repository > `Aungnaingthar/ColdWarIronCurtain`.
   Local path: `Documents\Paradox Interactive\Hearts of Iron IV\mod`
   (so the folder becomes `...\mod\ColdWarIronCurtain`).
3. In GitHub Desktop, switch "Current branch" to `iron-curtain-expanded`.
4. Copy `Cold_War_Iron_Curtain.mod` from that folder up one level into the `mod` folder.
5. In the HOI4 launcher, enable **Cold War Iron Curtain Dev Build** and turn off the
   Steam Workshop "Cold War Iron Curtain", so only one copy loads.

## Getting Iron Curtain's updates later

On GitHub, open your fork and press **Sync fork** on `development-branch`, then merge
`development-branch` into `iron-curtain-expanded` (GitHub Desktop: Branch > Merge into current branch).

Personal use only: please do not upload this version to the Steam Workshop.
